# Sabina Azimova Dental Atelier

Official landing page and clinical showcase for Dr. Sabina Azimova (Dentist & Hygienist, Saint Petersburg).

## Features
- **Swiss GBT AirFlow Protocol**: Glycine powder polishing & Piezon ultrasound scaling showcase.
- **Pediatric Care**: Playful adaptation and dental care for children.
- **Interactive Before/After**: Real patient clinical macro photography slider.
- **Bilingual Interface**: Full support for Russian (RU) and English (EN).
- **Direct Concierge Booking**: Integrated Telegram booking and appointment request form.

## Tech Stack
- HTML5, Modern Vanilla CSS3 Design System, Vanilla JavaScript Engine.
- Deployed on GitHub Pages.
